# FWD Quiz

A simple frontend web quiz application built using HTML, CSS, and JavaScript.

## Features

- Interactive multiple-choice quiz
- Responsive design for desktop and mobile devices
- Instant feedback on answers
- Score tracking

## Getting Started

### Prerequisites

No special requirements—just a modern web browser.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/dharani4645/FWD_Quiz.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd FWD_Quiz
   ```
3. **Open `index.html` in your browser:**
   - Double-click the `index.html` file
   - Or right-click and choose “Open with” your preferred browser

## Usage

- Start the quiz by clicking the “Start” button.
- Select answers for each question.
- View your score at the end.
